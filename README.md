# Hotel Room Management System

A Java Servlet–based hotel room management system designed using object-oriented programming (OOP) principles.

## Features
- Manages hotel room availability efficiently using a Binary Search Tree (BST)
- Sorts registered guests using the Quick Sort algorithm
- Implements OOP concepts such as encapsulation, inheritance, and abstraction
- Server-side logic handled using Java Servlets

## CRUD Operations
- **Create:** Register new guests and add room details
- **Read:** View guest information and check room availability
- **Update:** Modify existing guest and room records
- **Delete:** Remove guest entries and room data when required

## How to Run
1. Clone the repository
2. Open the project in an IDE such as IntelliJ IDEA or Eclipse
3. Configure and run the project using Apache Tomcat
4. Access the application through the browser

## Purpose
This project was developed to strengthen understanding of Java backend development, object-oriented design, and core data structures and algorithms.
